Privacy Policy

Effective date: October 9, 2026

This policy describes the Google Drive data handling of GitHub Runner Drive ADC, an independently operated integration for a private artifact-processing workflow. It also describes this informational website.

1. Information accessed

The application uses a Google authorized-user grant scoped to https://www.googleapis.com/auth/drive.file. The operator explicitly selects a transcript-materialization folder using Google Picker. Under this grant, the integration can obtain the selected folder's metadata and create application-authorized transcript files there.

The wider internal artifact-processing system may separately access authorized audio/video source files, file metadata, and derived content through a distinct Google Drive control identity. That control identity is not the same as the limited authorized-user OAuth credential described above.

2. Purpose and use of data

Access is used to check the selected folder's permissions, create derived transcripts, verify file identity and contents, and organize these files at the operator's managed Google Drive destinations. Source media may be processed by an operator-controlled local transcription runtime to produce those transcripts. Content is not used for advertising or unrelated profiling.

3. Storage and security

Google Drive stores the authorized source and derived files. The OAuth refresh credential is maintained on an operator-controlled host outside public repositories and supplied to the processing container as a read-only mounted file. A separate ephemeral Google identity is used for workflow control tasks. The public website does not store OAuth secrets, source media, or transcripts.

Reasonable technical restrictions are used to reduce unnecessary access, including application-bounded OAuth scope, explicit folder selection, and checks of managed file identity and contents. No storage or transmission system can promise absolute security.

4. Sharing and third parties

The integration is not offered as a data marketplace and does not sell Google user data or share it for advertising. Google provides Drive storage and OAuth services. GitHub provides workflow coordination infrastructure and hosting for this informational website; operational status metadata may be processed through workflow systems. Transcript bodies and OAuth secrets are not intentionally published to this website or a public source repository.

The integration's use and transfer of information received from Google APIs is limited to providing or improving its user-facing functionality and other uses allowed under the Google API Services User Data Policy, including applicable Limited Use requirements.

5. Retention and deletion

Derived files remain in the operator's managed Google Drive storage until removed or retained under the applicable artifact lifecycle policy. This application does not claim a fixed universal retention period. The operator can delete managed content in accordance with that policy. Local credentials are replaced or removed when access is no longer required or is revoked.

6. Revoking authorization

The authorizing Google account owner can revoke the application's access from the Google Account's third-party connections controls. Revocation prevents future authorized-user access once effective; it does not automatically delete existing Google Drive files already created or managed by the workflow.

7. This website

The informational pages do not include analytics scripts, interactive forms, advertising trackers, or custom cookies. Standard server requests and access logs may be handled by the website hosting provider according to its own policies.

8. Updates and contact

This policy may be updated if the processing architecture or data practices change. The effective date above will change when a revision is published. For questions or privacy-related requests, contact the application operator using the support email displayed on the Google OAuth consent screen.
