Independent, operator-managed integration

Private artifact processing, with limited Google Drive access.

GitHub Runner Drive ADC supports an operator-controlled workflow that turns authorized source media into derived transcripts and organizes the resulting files in Google Drive. The application is an internal utility, not a general-purpose public file service.

Google DriveLimited OAuth scopeSelf-hosted processing

How it works

1. Limited authorization

An authorized operator grants the Google Drive drive.file scope and selects the designated transcript-staging folder through Google Picker.

2. Transcript materialization

The integration uses the authorized-user credential to create derived transcript files in that selected staging folder.

3. Controlled file handling

A separate, independently authorized control identity validates file identity and contents before moving files to their managed destinations.

4. Operator management

Workflow execution, access management, and lifecycle decisions are controlled by the operator rather than visitors to this website.

Why Google Drive authorization is requested

The integration requests https://www.googleapis.com/auth/drive.file to work with the specific application-authorized files and create the derived transcript in the operator-selected folder. It does not ask the authorized-user OAuth grant for unrestricted access to every file in a Google Drive account.

Separate internal control-plane access is used to manage previously authorized source and derived files. This is not an OAuth sign-in or callback website; the public pages here only explain how the integration operates.

Privacy by design. This informational website has no sign-in form, tracking scripts, or data-upload interface. Transcript contents, OAuth credentials, and private runner settings are not published on this site.

Data practices and support

Read the Privacy Policy for the categories of Google data involved, processing and storage details, retention, and how to revoke access. You can contact the operator using the support email presented on the Google OAuth consent screen.
